# Aimens (Айменс): проверка установщика

Небольшой открытый инструмент для локальной проверки SHA-256 и размера скачанного установщика Aimens. Python 3.9 или новее; дополнительные библиотеки не требуются.

**Официальный сайт Aimens — [aimensproxy.com](https://aimensproxy.com/).**
Приложения Aimens предназначены для защищённого соединения на Android и Windows.
[Установщики и инструкции](https://aimensproxy.com/downloads/) · [Помощь Aimens](https://aimensproxy.com/help/).

## Что проверяется

Скрипт читает выбранный файл на вашем устройстве и сравнивает его размер и SHA-256 с `releases.json`. Он не скачивает и не запускает установщик, не передаёт файл в сеть и не требует учётной записи Aimens.

Совпадение означает, что прочитанные байты соответствуют зафиксированному SHA-256 и размеру. Эта проверка не устанавливает личность издателя, не заменяет проверку цифровой подписи и не является проверкой программы на вредоносность.

| ID | Установщик | Размер, байт |

| `android-1.0.53` | `aimens-proxy-android-1.0.53.apk` | 79 673 625 |

## Использование

Скачайте установщик со страницы загрузок Aimens и сохраните файлы этого репозитория вместе. Откройте терминал в папке со скриптом.

Windows:

```powershell
py -3 aimens_checksum.py ".\aimens-proxy-windows-7.28.0.exe"
```

Linux или macOS:

```sh
python3 aimens_checksum.py ./aimens-proxy-android-1.0.53.apk
```

Если установщик переименован, выберите версию явно:

```sh
python3 aimens_checksum.py ./app.apk --release android-1.0.53
```

Список зафиксированных версий и JSON-результат:

```sh
python3 aimens_checksum.py --list
python3 aimens_checksum.py ./app.apk --release android-1.0.53 --json
```

Коды завершения: `0` — размер и SHA-256 совпали; `1` — файл отличается; `2` — ошибка аргументов, чтения или справочных данных. При несовпадении проверьте выбранную версию и завершение загрузки, затем повторно сравните файл.

## Проверки инструмента

```sh
python3 -B -m unittest discover -s tests -v
```

Тесты используют временные файлы и не требуют сети, установленных приложений или учётной записи. Они проверяют сам инструмент; проверка конкретного скачанного APK или EXE выполняется отдельной командой выше.
